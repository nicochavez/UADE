# Big Data vs. Data Mining

Tabla comparativa completa de la Clase 6 (diapositiva 61). Es una pregunta
directa del [[modelo-primer-parcial]].

| Aspecto | **Big Data** | **Data Mining** |
|---|---|---|
| **Definición** | Conjunto de tecnologías y procesos para manejar grandes volúmenes de datos | Proceso de analizar datos para descubrir patrones ocultos |
| **Objetivo** | Almacenar, procesar y gestionar grandes cantidades de datos | Extraer conocimiento útil a partir de los datos |
| **Enfoque** | Infraestructura y volumen de datos | Análisis e interpretación |
| **Tipo de datos** | Datos masivos, estructurados y no estructurados | Datos previamente almacenados (muchas veces provenientes de Big Data) |
| **Función principal** | Recolección, almacenamiento y procesamiento | Análisis, predicción y descubrimiento de patrones |
| **Nivel de análisis** | **Bajo** (gestión de datos) | **Alto** (inteligencia y conocimiento) |
| **Tecnologías** | Hadoop, Spark, bases NoSQL, cloud computing | Algoritmos de IA, machine learning, estadística |
| **Ejemplo** | Netflix **almacena** millones de datos de usuarios | Netflix **analiza** esos datos para recomendar películas |
| **Relación** | Es la **base que provee** los datos | **Utiliza** los datos para generar valor |

## La forma corta de recordarlo

**Big Data es el "dónde" y el "cuánto"; Data Mining es el "qué significa".**

No son competidores ni alternativas: son **etapas sucesivas de la misma
cadena**. El Big Data resuelve el problema de tener los datos; el Data Mining
resuelve el problema de que los datos no sirven de nada por sí solos.

## Cómo encaja el Business Intelligence

La cadena completa que plantea la materia tiene tres eslabones, no dos:

```
Big Data          →   Data Mining        →   Business Intelligence
(infraestructura)     (descubrimiento)       (decisión)
almacenar y            encontrar patrones     presentar la información
procesar                ocultos                para decidir
```

- [[big-data]] responde **¿podemos guardar y procesar esto?**
- [[data-mining]] responde **¿qué patrones hay acá que no sabíamos?**
- [[business-intelligence]] responde **¿qué decisión tomo con esto?**

El BI trabaja sobre datos históricos y actuales para **decisiones
fundamentadas**; el Data Mining busca lo **desconocido**. Un tablero de BI
muestra que las ventas cayeron 12 %; el Data Mining descubre *por qué* y *qué
clientes van a irse el mes que viene*.
